# Data to download

1. Official **Lost in Transcription Development Data: Indonesian-Javanese** →
   `data/indonesian_javanese/development/`.
2. **Jember Javanese Spontaneous Speech Corpus** →
   `data/indonesian_javanese/jember/`.
3. Official **Submission Format** →
   `submission_formats/indonesian_javanese/submission_format.csv`.

Set `LIT_DEV_DIR=data/indonesian_javanese/development` and
`LIT_JEMBER=data/indonesian_javanese/jember` before running the notebook.
